# Sesión 2026-07-04 — Creación del proyecto

## Contexto
Álvaro usa el chat de WhatsApp consigo mismo como inbox de tareas/notas/imágenes. Quiere sustituirlo, pero el riesgo nº1 identificado es que cualquier app nueva tenga MÁS fricción que WhatsApp.

## Decisiones tomadas
| Decisión | Elección | Por qué |
|---|---|---|
| Canal de captura | Bot de Telegram | Cero cambio de hábito; API gratis; WhatsApp API es de pago y compleja |
| Organización | Dashboard PWA instalable en iPhone | Visual, sin App Store, sin Mac |
| Hosting | Cloudflare (ya tiene dominio y proyectos ahí) | Workers+D1+R2+AI todo en capa gratuita |
| IA | Workers AI Llama 3.1 8B | Gratis (~10k neuronas/día), clasifica tipo/prioridad/categoría/fecha |
| Recordatorios | Mensajes del propio bot (cron diario) | Fiable en iPhone; push de PWA en iOS es frágil |

## Hecho en la sesión
- Proyecto completo en `taskbot/`: worker (5 módulos JS), dashboard PWA (vanilla), schema D1, wrangler.toml, README con despliegue paso a paso.
- Validado: sintaxis (node --check) y resolución de imports (esbuild bundle limpio, 15.9kb).
